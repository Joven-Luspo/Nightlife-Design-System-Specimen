Foundations

Selective reset

The reset removes unnecessary browser spacing, keeps sizing responsive, makes images responsive, and lets form controls use the same font. 


* {
  box-sizing: border-box;
}

body {
  margin: 0;
}

img {
  max-width: 100%;
}

button,
input,
select {
  font: inherit;
}
Usage note

The reset is intentionally small and keeps useful browser defaults.
